# نظام حساب الرسوم القضائية

نموذج Full‑Stack عربي RTL لتوحيد تقدير الرسوم القضائية المصرية عند رفع الدعوى وعند التسوية النهائية، مع تفسير كل بند وربطه بمصدره وإصدار القواعد الذي استُخدم.

> **حد قانوني مهم:** هذا الإصدار أداة تقدير ومراجعة، وليس أمر تحصيل. القواعد الموسومة «محجوبة» أو «مرشحة» لا تدخل الإجمالي حتى يكتمل سندها ويعتمدها مراجع قانوني مستقل.

## ما يعمل الآن

- محرك حساب بدقة المليم، دون أعداد عشرية عائمة في التخزين.
- الرسم النسبي بشرائحه، وحدود التحصيل المقدم، والتسوية على المقضي به.
- الرسوم مجهولة القيمة بحسب درجة المحكمة والحالة المستعجلة.
- صندوق الخدمات وأتعاب المحاماة، مع حجب طابع صندوق تكريم الشهداء عن قيد الدعوى إلى أن تُعتمد خريطة الخدمات الخاضعة بدل تعميمه من شرط القيمة وحده.
- تفسير آلي: الوعاء، المعادلة، المبلغ، القانون والمادة، وإصدار القاعدة.
- فصل تقديرات الموظفين عن أحداث التحصيل الفعلي في لوحة القيادة.
- 8 محاكم تجريبية في لوحة المتابعة و305 مسميات دعاوى وطلبات تشغيليًا مربوطة بـ63 ملفًا قانونيًا عبر 11 ولاية قضائية؛ منها حالات المادة 76 ومجموعات المادة 49 للأحوال الشخصية كأنواع صريحة لا كتصنيف عام مبهم.
- نوع الدعوى يحدد مسار التقييم والوقائع المطلوبة ودرجة المحكمة المسموح بها؛ الأنواع غير المكتملة تتوقف بأمان بدل تمريرها إلى معادلة عامة.
- توجد مسارات وقائع مستقلة للإيجار والعقود والحقوق العقارية والحقوق الدورية والشركات والتنفيذ والعمل، إضافة إلى قواعد صريحة للاستئناف والنقض المدني/التجاري والجنائي والدستوري ومجلس الدولة والأسرة والمحاكم الاقتصادية وطلب إشهار الإفلاس.
- لكل نوع سياسة تسوية نهائية صريحة: على الوعاء المقضي به، أو رسم ثابت سبق سداده، أو إعفاء كل المراحل، أو إدانة جنائية، أو رد/مصادرة كفالة دستورية، أو عملية لا تنطبق عليها مرحلة التسوية، أو توقف للمراجعة.
- التسوية تميز الحكم الكامل والجزئي والرفض وعدم القبول والصلح والترك والشطب، وانتهاء/سقوط الخصومة دون فصل، واعتبار الدعوى أو الاستئناف كأن لم يكن، والإحالة بعد النقض، وتفصل المطلوب تحصيله عن مبلغ الرد التقديري.
- الصلح يقرأ قيمة المصالح عليه، وحد الألف جنيه، والالتزام المعلوم القابل للتنفيذ في الدعوى مجهولة القيمة، وحظر الرد في الدعوى مخفضة القيمة؛ ولا يطبق تخفيض نصف الرسم على الترك بعد الجلسة الأولى.
- أدوار منفذة على الخادم: موظف تقدير، رئيس قلم، مراجع قانوني، مدير المشروع المحدد، قيادة.
- رئيس القلم يقترح وينشر — بعد مراجعة مستقلة — لمحكمته فقط؛ ومدير المشروع الوحيد المحدد يملك التغيير العام.
- تغييرات القواعد المنشورة ليست وصفية: تحفظ كمعاملات رقمية مقيدة وتدخل فعلًا في المحرك بحسب المحكمة وتاريخ الحساب، مع إظهار التغيير المطبق في نتيجة التقدير.
- سجل تدقيق متسلسل ببصمات SHA‑256 وقاعدة SQLite محلية للنموذج.
- سجل مصادر وقواعد يوضح المنشور والمسودة والمحجوب والفجوات.

## التشغيل

للعرض المباشر على جهاز Windows، انقر مرتين على `تشغيل النظام.cmd`. يفتح الملف نسخة الإنتاج على `http://127.0.0.1:4174/`، وإذا كان النظام يعمل بالفعل يفتح الصفحة دون تشغيل نسخة ثانية.

### حسابات العرض

| الصلاحية | اسم المستخدم | كلمة المرور | النطاق |
|---|---|---|---|
| موظف تقدير | `estimator` | `Fees@2026` | إنشاء التقديرات |
| رئيس قلم | `supervisor` | `Review@2026` | محكمة شمال القاهرة فقط |
| مراجع قانوني | `legal` | `Legal@2026` | مراجعة القواعد والمصادر |
| مدير المشروع | `project.manager` | `Project@2026` | النشر العام الحصري |
| مستخدم قيادي | `leadership` | `Reports@2026` | عرض المؤشرات فقط |

هذه بيانات عرض محلية وليست إعداد إنتاج. قبل النشر الفعلي يجب تعطيل `JUDICIAL_FEES_ENABLE_DEMO_LOGIN`، وتغيير مفتاح الجلسات، والربط بمزود الهوية الحكومي.

المتطلبات: Node.js 24+ وpnpm 11.

```powershell
pnpm install
pnpm dev
```

أو شغّل ملف `تشغيل النظام.cmd` بنقرتين. ثم افتح `http://127.0.0.1:4173/`. الدخول السريع بالأدوار متاح في وضع التطوير فقط.

التحقق:

```powershell
pnpm typecheck
pnpm test
pnpm build
```

بيانات SQLite المحلية تُنشأ في `.data/judicial-fees.db`، وهي مستبعدة من Git.

## خريطة المستودع

- `src/domain/`: محرك الحساب، الأنواع، سجل القواعد والمصادر، واختبارات الحدود.
- `server/`: API، المصادقة التجريبية، الصلاحيات، SQLite وسجل التدقيق.
- `src/pages/`: الحاسبة، لوحة القيادة، القواعد، المصادر، التقديرات والتدقيق.
- `docs/`: المعمارية، سجل القواعد القانونية، جودة المصادر والأمن.
- `scripts/`: جرد/OCR المصادر واستخراج أنواع الدعاوى من Excel.

## قبل الإنتاج

يلزم اعتماد الإدارة القانونية للقواعد المحجوبة، استبدال SQLite بـ PostgreSQL عالي الإتاحة، ربط هوية حكومية OIDC، تكامل نظام التحصيل الفعلي، TLS، إدارة أسرار مركزية، وبيئة قبول تشغيلي بوقائع رسوم تاريخية موقعة. التفاصيل في [المعمارية](docs/architecture-ar.md) و[سجل القواعد](docs/legal-rulebook-ar.md).
